1. INTRODUCTION                                       *org-columnview-introduction*

A port of the Emacs Org column view (|org-colview|) for Neovim. The column
view overlays a tabular structure over the headlines of an org buffer, and
renders the agenda as a table of columns. The values can be edited in place,
and the layout of the columns can be changed and is written back to the
buffer, like in Emacs.

==============================================================================
2. REQUIREMENTS                                       *org-columnview-requirements*

nvim-orgmode is required for the org file, headline and agenda handling:

  https://github.com/nvim-orgmode/orgmode

The plugin works with the `master` branch of nvim-orgmode, no patches are
needed. It uses internal modules of nvim-orgmode, which are not a stable
public API, so changes there can break the plugin.

==============================================================================
3. SETUP                                                     *org-columnview-setup*

The plugin has to be set up after nvim-orgmode, because the setup call of
nvim-orgmode creates the instance that the plugin registers itself on: >lua

    require('orgmode').setup()
    require('org-columnview').setup()
<
With lazy.nvim: >lua

    {
      'nvim-orgmode/orgmode',
      dependencies = { 'nvim-orgmode/org-columnview.nvim' },
      config = function()
        require('orgmode').setup()
        require('org-columnview').setup()
      end,
    }
<

4. MAPPINGS                                               *org-columnview-mappings*

Entry points: >

    org_columns            <prefix>xc    Toggle the column view in an org
                                          buffer. It shows the subtree of the
                                          headline under the cursor, or the
                                          whole file when the cursor is
                                          before the first headline.
    org_agenda_columns     <prefix>ac    Open the agenda as a column view.
<
The prefix is the one of nvim-orgmode (|orgmode-mappings|), `<Leader>o` by
default, so the defaults are `<Leader>oxc` and `<Leader>oac`.

In the agenda, `<prefix>xc` opens the column view of the agenda as well, like
in Emacs, where the same key opens the view of the current buffer. The column
view is also an entry of the agenda prompt (`<prefix>oa`), under the key `c`.

While the column view is open, these buffer local mappings are available: >

    h / l         Previous / next column
    k / j         Previous / next row
    1 ... 9, 0    Select the 1st..10th allowed value
    n / p         Next / previous allowed value
    e             Edit the value at point
    C-c C-c       Toggle the checkbox at point, or quit the column view
    q             Quit the column view
    v             View the full value of the current cell
    a             Edit the allowed values of the current column
    < / >         Narrow / widen the current column
    S-M-Right     Insert a column
    S-M-Left      Delete a column
    M-Left        Move the current column left
    M-Right       Move the current column right
    M-Up          Move the current row up
    M-Down        Move the current row down
    s             Edit the current column attributes
    r             Refresh the view from the file
    c / o         Switch between content and overview
    C-c C-o       Open the link at point
    C-c C-t       Change the TODO state
    g?            Show the help
<
The cell under the cursor is highlighted. Moving the cursor to another
headline moves the highlighted cell with it.

5. COLUMN FORMAT                                           *org-columnview-format*

A column format is a space separated list of column specifications: >

    %[width]PROPERTY[(Title)][{summary}][{allowed values}]
<
    width              Column width in characters (optional)
    PROPERTY           Any property name, or one of the special columns
    (Title)            Display title (optional, defaults to the property)
    {summary}          Summary type for entries with children (optional)
    {allowed values}   Comma separated list, whitespace separated when
                       there is no comma, or `NAME_ALL` to reference the
                       `NAME_ALL` property (optional). A referenced
                       `NAME_ALL` property is looked up on the entry and
                       its ancestors, and finally file-wide via
                       `#+PROPERTY: NAME_ALL ...` or `#+NAME_ALL: ...`

Special column names: `ITEM`, `CLOCKSUM`, `CLOCKSUM_T`, `AGE`, `TAGS`,
`ALLTAGS`, `TODO`, `PRIORITY`, `CATEGORY`, `SCHEDULED`, `DEADLINE`, `CLOSED`,
`TIMESTAMP`, `TIMESTAMP_IA`, `FILE` and `BLOCKED`.

Summary types: `+` (sum), `$` or `+;%.2f` (formatted sum), `:` (duration
sum), `:min`, `:max`, `:mean` (duration extremes and mean), `min`, `max`,
`mean` (numeric), `X`, `X/`, `X%` (checkboxes), `@min`, `@max`, `@mean` (age
extremes and mean) and `est+` (low/high estimates).

The format is looked up in this order: a `COLUMNS` property on the headline
or one of its ancestors, the `#+COLUMNS:` keyword of the file, and finally
the `default_format` option.

Changing the column layout (attributes, width, insert, delete, move) is
written back to the buffer, like in Emacs: into the `:COLUMNS:` property of
the headline the view started at when it has one, otherwise into the first
`#+COLUMNS:` keyword (created before the first headline if missing). The
agenda column view keeps such edits in memory only.

6. CONFIGURATION                                     *org-columnview-configuration*

>lua
    require('org-columnview').setup({
      -- Column format used when no COLUMNS property or #+COLUMNS: keyword
      -- is found
      default_format = '%25ITEM %10Effort(Effort){:} %10CLOCKSUM %10CLOCKSUM_T %10Tags %10TODO',
      -- Column format used in the agenda when nothing else is defined
      default_format_for_agenda = nil,
      -- Column format that overrides everything in the agenda
      overriding_columns_format = nil,
      -- Called with the column title and the value to produce the text that
      -- is shown. Return nil to keep the original value.
      modify_value_for_display_function = nil,
      -- Prefix of the mappings, defaults to the prefix of nvim-orgmode
      prefix = nil,
      mappings = {
        org_columns = '<prefix>xc',
        org_agenda_columns = '<prefix>ac',
        column_view = {
          quit = 'q',
          -- ... see the mappings above
        },
      },
    })
<
A mapping that is configured for nvim-orgmode wins over the one of the
plugin.

7. DIFFERENCES TO EMACS                                *org-columnview-differences*

The column view is a port, not a copy. The known differences to Emacs are
tracked in the implementation plan of the repository:

  https://github.com/nvim-orgmode/org-columnview.nvim
